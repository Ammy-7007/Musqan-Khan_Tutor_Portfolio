# 📚 English Tutor Portfolio Website

A modern and responsive portfolio website created for an English tutor to showcase professional teaching experience, educational background, certifications, skills, and tutoring services. The website provides an online presence to help students and parents learn more about the tutor and available learning opportunities.

## 🌟 Features

- Clean and professional user interface
- Fully responsive design
- Home section with tutor introduction
- About section
- Teaching experience showcase
- Education and qualification section
- Certification display
- Skills and expertise section
- Tutoring services section
- Contact section
- Certificate image integration
- Mobile-friendly layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Font Awesome Icons
